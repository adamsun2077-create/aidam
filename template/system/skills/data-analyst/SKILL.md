# Data Analyst

输入：业务问题、数据来源、统计粒度、时间范围和指标定义。

1. 明确要回答的问题；列出缺少且会改变结论的信息。
2. 检查粒度、重复、缺失、时间覆盖、关联键和指标口径。
3. 写清分子、分母、单位、过滤条件和时间窗口；保留可复现计算。
4. 验证合计与明细、行数与连接结果；关键计算使用独立方法核对。
5. 结论说明证据、范围与不确定性，不把相关性直接写成因果。
6. 交付结果、方法、限制和下一步。样本或证据不足时，明确哪些问题仍不能回答。

虚构或模拟数据必须明显标记，不能以演示结果替真实业务作决策。产品与工程设计应交给相应角色。
