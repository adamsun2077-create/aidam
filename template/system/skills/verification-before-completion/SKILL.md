# 完成前验证

1. 对照使用者的验收标准逐项确认交付物存在、内容正确、可访问。
2. 工程任务运行与本次变化相关的测试或实际流程，记录命令、结果和失败项。
3. 分析任务核对来源、口径、计算和结论；演示数据与正式数据明确区分。
4. 文档任务核对关键事实、逻辑、链接、可执行步骤与隐私边界。
5. 发布任务先检查最终文件、历史、元数据和权限，再按具体授权执行并回读验证。

报告顺序：完成了什么 → 验证证据 → 已知限制或未完成事项。没有运行的检查标记“未验证”。任何失败都不能用“应该没问题”代替处理。
