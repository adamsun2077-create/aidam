# 隐私与分享边界

## 本项目包含什么

仅包含从零编写的通用工作规则、空白目录模板、五个基础技能、离线工具、虚构演练与测试。没有复制原工作区的项目、私人记忆、客户文件、聊天截图、云端交接资料、连接映射或 Git 历史。

## 两个目录分别保管

- **Starter 下载目录**：适合公开分发的通用方法与工具。
- **自己初始化的工作区**：私人工作区。以后加入的资料、记忆、日志和配置由自己保管，不能整库上传到公共仓库。

生成工作区的 `.gitignore` 默认忽略 `active/`、运营产出、记忆、配置、运行状态、外部连接和云端交接资料。忽略规则无法撤回已被 Git 跟踪的文件，也无法阻止其他上传工具；分享仍需明确选择。

## 分享工具如何工作

在 Starter 目录执行：

```sh
python3 aidam.py share --output ../aidam-starter.zip
```

导出边界由 `share-manifest.json` 和 `aidam.py` 的 `RELEASE_FILES` 双重限制。两者必须一致；不递归打包周围目录，不读取任意额外文件，不跟随符号链接。ZIP 内附 `CHECKSUMS.sha256`。

导出时会检查常见凭据格式、私钥标记、个人主目录路径和电子邮箱。只报告文件和问题类型，不回显疑似凭据。它无法理解所有业务隐私，也无法检测所有秘密格式，不能替代人工审阅。

清单变更需要同时修改程序中的白名单，并重新执行测试、导出和人工审阅。新增资料不要用“整目录放行”。

## 发布前

1. 解压分享 ZIP，逐项确认清单内容；确认没有个人资料、客户信息和其他人的作品。
2. 使用从这个 ZIP 创建的干净仓库，不连接私人工作区的 Git 历史。
3. 检查首次提交全部文件及作者元数据，确认公开边界和许可。
4. 得到仓库所有者对本次发布的明确授权后，再推送。

上传后的删除不能保证从他人克隆、平台缓存和历史中完全移除。若误传凭据，需立即撤销和轮换，并处理历史。

## 本地不等于不向模型发送

Starter 的工具离线运行，但你选用的 AI 客户端可能把读取的内容交给其模型服务处理。使用前了解所选工具的数据处理设置和公司要求，按任务提供最少必要内容。
