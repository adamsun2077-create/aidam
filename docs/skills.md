# 核心技能与扩展

技能是可复用的操作说明，每个技能以 `SKILL.md` 为入口。本模板提供两个核心技能：

| 技能 | 用途 |
|---|---|
| aidam-core | 工作区规则与工具导航 |
| verification-before-completion | 声称完成、修复或发布前核对实际证据 |

按任务目标、交付物与风险选择领域技能，不固定套用 CEO、VibeCoder、Data Analyst 三角色。简单任务直接完成，复杂任务再增加必要计划和验证；使用者保留业务决策与外部授权决定。

## 怎样加载

执行规则读取 `system/AIDAM.md`，需要工具导航时读 aidam-core，领域技能按需读取。文件不保证自动注册到每个客户端，按工具支持方式引用。Starter 不修改全局技能目录。

## 怎样新增

开发时放 `active/skills/技能名/SKILL.md`，写明适用任务、输入、步骤、权限边界、验收和失败处理。用虚构或公开输入验证，再晋升到 `system/skills/技能名/`。工具入口引用唯一源，避免复制正文长期分叉。

本模板不附带个人客户技能、付费插件或第三方技能包；自行核验来源、许可与依赖。
