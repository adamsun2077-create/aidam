# 核心技能与扩展

技能是可复用的操作说明，每个技能以 `SKILL.md` 为入口。本模板的五个技能均为面向 Starter 重新编写的精简版本。

| 技能 | 何时读 | 产出要求 |
|---|---|---|
| aidam-core | 每次开始或角色不明确时 | 明确主交付物、主角色与边界 |
| ceo | 商业目标、用户、优先级与方案 | 区分事实、假设、建议和待决策项 |
| vibecoder | 代码、架构、排错与测试 | 可运行变更、验证证据和已知限制 |
| data-analyst | 指标、数据处理、实验与分析 | 口径、质量、方法、证据和可复现结果 |
| verification-before-completion | 任何完成声明前 | 验证结果和未完成事项 |

CEO 不负责代码实现，VibeCoder 不替使用者决定商业方向，Data Analyst 不用不充分数据替代产品或工程决策。混合任务围绕最终交付物确定主角色，必要时顺序切换。

## 怎样加载

先让 AI 读取 `system/skills/aidam-core/SKILL.md`，再读取当前角色和必要技能。这里的文件不保证自动注册到每个客户端；按工具支持的方式手动引用即可。Starter 不修改使用者的全局技能目录。

## 怎样新增

开发时放 `active/skills/技能名/SKILL.md`。至少写明：适用任务、输入、步骤、权限边界、验收标准、失败处理。用虚构或公开输入实测，再晋升到 `system/skills/技能名/`，保持唯一源。

接入新工具时，优先让工具引用这份源；如需工具自己的适配文件，只写入口，不复制一份长期独立维护的技能正文。

本模板不附带个人积累的客户技能、付费插件或第三方技能包。需要额外技能时，使用者应自行核验来源、许可和依赖。
